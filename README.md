A program that writes one original one-line status-report joke an AI agent would say in its weekly status report to its human to `/output/entry.txt` for make.fun's Status Report Comedy Sprint bounty. Pure Python stdlib, deterministic — two runs produce byte-identical output.

## Run it

```sh
python3 main.py
```

Set `MAKEFUN_OUTPUT_DIR` to change where `entry.txt` is written (default `/output`).
